# DoDM 5200.01-V2 Enclosure 4: Table D — Banner Line Precedence Rules

> **Source**: DoDM 5200.01-V2, February 24, 2012 (Change 4, 7/28/2020), Enclosure 4
>
> **Parent**: [dodm-5200.01-enclosure4-requirements.md](../dodm-5200.01-enclosure4-requirements.md)

---

| ID | Condition | Banner Line Rule | Source |
|----|-----------|-----------------|--------|
| **BP-1** | Document has NOFORN and REL TO portions | NOFORN takes precedence in banner | E4-S10.d.7 |
| **BP-2** | Document has NOFORN and RELIDO portions | NOFORN takes precedence in banner | E4-A1-S4.d |
| **BP-3** | Document has NODIS and EXDIS portions | NODIS has priority over EXDIS in banner | E4-A2-S2.f |
| **BP-4** | Document has REL TO portions and uncaveated portions (DoD) | Banner contains only U.S. classification (no REL TO) | E4-S10.d.8.a |
| **BP-5** | Document has REL TO portions with no common country (DoD) | Banner reflects only U.S. classification | E4-S10.d.8.a.nocommon |
| **BP-6** | Document has DISPLAY ONLY in mixed portions | DISPLAY ONLY in banner ONLY if ALL portions have same DISPLAY ONLY country list | E4-S10.e.6 |
| **BP-7** | Document has FOUO in classified context | FOUO does NOT appear in banner | E4-S10.b.3a |
| **BP-8** | Document contains FGI | Banner reflects highest classification of any information including FGI | E4-S9.j |
