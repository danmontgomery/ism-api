# DoDM 5200.01-V2 Enclosure 4: Dissemination Control Markings

> **Source**: DoDM 5200.01-V2, February 24, 2012 (Change 4, 7/28/2020), Enclosure 4, Section 10
>
> **Parent**: [dodm-5200.01-enclosure4-requirements.md](../dodm-5200.01-enclosure4-requirements.md)

## 10.1 FOUO (For Official Use Only)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.b.1** | FOUO is a control marking for unclassified information | S10.b.(1) |
| **E4-S10.b.3** | FOUO portions within a classified document shall be marked `(U//FOUO)` | S10.b.(3) |
| **E4-S10.b.3a** | FOUO shall NOT appear in the overall classification banner of a classified document (classification adequately protects the unclassified info) | S10.b.(3) |
| **E4-S10.b.3b** | Exception: When page markings reflect per-page classification, unclassified pages with FOUO use banner: `UNCLASSIFIED//FOR OFFICIAL USE ONLY` or `UNCLASSIFIED//FOUO` | S10.b.(3) |

## 10.2 ORCON (Originator Controlled)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.c.3** | ORCON may be used with TOP SECRET, SECRET, or CONFIDENTIAL | S10.c.(3) |
| **E4-S10.c.4** | Banner: `[classification]//ORCON`. Portion: `([classification]//OC)` | S10.c.(4) |
| **E4-S10.c.4a** | If any portion is ORCON, ORCON must appear in the banner line | S10.c.(4) |

## 10.3 REL TO (Authorized for Release To)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.d.3** | REL TO may be used with TOP SECRET, SECRET, CONFIDENTIAL, or CUI | S10.d.(3) |
| **E4-S10.d.4** | Format: `[classification]//REL TO [country codes]` | S10.d.(4) |
| **E4-S10.d.4.order** | Trigraphic country codes listed: USA first, then other countries alphabetically, then coalition/organization tetragraphs alphabetically. Separated by comma and space. | S10.d.(4) |
| **E4-S10.d.5** | "REL TO USA" without any other countries is NOT an approved marking | S10.d.(5) |
| **E4-S10.d.6** | Portion marking `(REL)` may be used when portion's releasable countries are the same as banner line REL TO countries | S10.d.(6) |
| **E4-S10.d.6a** | If countries are different, portion marking must list all applicable countries | S10.d.(6) |
| **E4-S10.d.7** | REL TO shall NOT be used with NOFORN in the banner line | S10.d.(7) |
| **E4-S10.d.7a** | When a document contains both NOFORN and REL TO portions, use NOFORN in the banner line | S10.d.(7) |
| **E4-S10.d.8** | REL TO should be in banner only when entire document is releasable to countries listed | S10.d.(8) |
| **E4-S10.d.8.a** | Within DoD (non-IC): if document has REL TO portions and uncaveated portions, banner shall contain only U.S. classification (no REL TO) | S10.d.(8)(a) |
| **E4-S10.d.8.a.nocommon** | If no common country across all REL TO portions, banner reflects only U.S. classification | S10.d.(8)(a) |
| **E4-S10.d.8.b** | IC (DNI) exception: combination of REL TO and uncaveated national intelligence is marked NOFORN in banner | S10.d.(8)(b) |

## 10.4 DISPLAY ONLY

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.e.3** | DISPLAY ONLY may be used with TOP SECRET, SECRET, or CONFIDENTIAL | S10.e.(3) |
| **E4-S10.e.4** | DISPLAY ONLY may NOT be used with RELIDO or NOFORN | S10.e.(4) |
| **E4-S10.e.4a** | DISPLAY ONLY shall NOT be used with other dissemination controls (e.g., REL TO) in either portion or banner, UNLESS authorized by other policy guidance and established sharing arrangements | S10.e.(4) |
| **E4-S10.e.5** | Format: `[classification]//DISPLAY ONLY [country codes]` | S10.e.(5) |
| **E4-S10.e.5.order** | Trigraphic country codes first in alphabetical order, then coalition/organization tetragraphs alphabetically, separated by comma and space | S10.e.(5) |
| **E4-S10.e.6** | DISPLAY ONLY appears in banner ONLY if ALL portions are authorized for DISPLAY ONLY to the SAME list of countries | S10.e.(6) |
| **E4-S10.e.6a** | REL TO and DISPLAY ONLY may appear in same banner ONLY if EVERY portion is authorized for REL TO [same list] AND DISPLAY ONLY [same list] | S10.e.(6) |
