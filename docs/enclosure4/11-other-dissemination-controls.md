## 11.1 ACCM (Alternative Compensatory Control Measures)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S11.a.2** | Banner: classification, "ACCM," and the program nickname. Hyphen separates ACCM and nickname (e.g., `SECRET//ACCM-FICTITIOUS EFFORT`) | S11.a.(2) |
| **E4-S11.a.2a** | Multiple nicknames separated by a forward slash (`/`) (e.g., `SECRET//ACCM-FICTITIOUS EFFORT/TEA LEAF`) | S11.a.(2) |
| **E4-S11.a.3** | Portion: classification abbreviation, "ACCM," and nickname. Hyphen separates ACCM and nickname. Multiple nicknames separated by `/` | S11.a.(3) |
| **E4-S11.a.4** | Portion mark `ACCM` (without nickname) may be used when applicable programs match banner line | S11.a.(4) |
| **E4-S11.a.4a** | If applicable programs differ from banner, complete portion marking must be used | S11.a.(4) |
| **E4-S11.a.5** | Only the full nickname may be used after ACCM. No abbreviations, digraphs, or trigraphs allowed. | S11.a.(5) |
