# DoDM 5200.01-V2 Enclosure 4: Marking Standard Requirements

> **Source**: DoDM 5200.01-V2, February 24, 2012 (Change 4, 7/28/2020), Enclosure 4, pages 63-105
>
> **Purpose**: Traceable requirements for generating a comprehensive test suite for classification string construction and validation.
>
> **Traceability Format**: Each requirement is tagged `[E4-S{section}.{paragraph}]` mapping to Enclosure 4 section and paragraph. Appendix requirements use `[E4-A{appendix}-S{section}.{paragraph}]`.

---

## 1. Overall Marking Structure

### 1.1 Marking Syntax

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S1.b** | The required marking syntax for classified U.S. documents is: `CLASSIFICATION//SCI//SAP//AEA//FGI//DISSEM//OTHER DISSEM` | S1.b |
| **E4-S1.b.1** | A double forward slash (`//`) shall separate marking categories | S1.b.(1) |
| **E4-S1.b.1a** | A single forward slash (`/`) shall separate multiple types within the same marking category (e.g., `SCI/SCI`, `DISSEM/DISSEM`) | S1.b.(1) |
| **E4-S1.b.1b** | Hyphens (`-`) without spaces shall separate a control system from its sub-control/compartment (e.g., `SI-G`, `RD-N`) | S1.b.(1) |
| **E4-S1.a** | Markings must appear in the order listed in Figure 25 (see category ordering below) | S1.a |
| **E4-S1.b.2** | The classification level in the banner line must be in English and spelled out completely | S1.b.(2) |
| **E4-S1.b.2a** | Other control markings (SCI, SAP, dissemination) in the banner may be spelled out or abbreviated using authorized abbreviations | S1.b.(2) |
| **E4-S1.b.3** | Control markings (SCI, SAP, AEA, dissemination) are required in both banner line and portion markings where applicable | S1.b.(3) |
| **E4-S1.b.3a** | Double forward slashes (`//`) separate the classification level from control markings, and different categories from each other | S1.b.(3) |

### 1.2 Category Ordering (Figure 25)

Categories MUST appear in this order when present:

| Position | Category | Examples |
|----------|----------|----------|
| 1 | US Classification | TOP SECRET, SECRET, CONFIDENTIAL |
| 2 | SCI Control System | HCS, SI, TALENT KEYHOLE |
| 3 | SAP | SAR-{nickname} |
| 4 | Atomic Energy Program (AEA) | RESTRICTED DATA, FORMERLY RESTRICTED DATA, CNWDI |
| 5 | FGI (in US documents) | FGI {country codes} |
| 6 | Dissemination Controls | FOUO, ORCON, IMCON, NOFORN, PROPIN, REL TO, RELIDO, FISA, DISPLAY ONLY |
| 7 | Other Dissemination Controls | ACCM, EXDIS, NODIS |

### 1.3 Mutual Exclusivity of Classification Systems

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S1.d** | U.S. classification markings, non-U.S. classification markings (FGI), and JOINT classification markings are mutually exclusive. They may NOT be used at the same time in a banner line or a portion mark. | S1.d |

### 1.4 Dissemination Control Rules

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S1.b.4a** | Multiple entries may be chosen from dissemination control categories if applicable; listed in Figure 25 order | S1.b.(4)(a) |
| **E4-S1.b.4b** | In classified documents with dissemination controls, unclassified portions without controls shall be marked `(U)` | S1.b.(4)(b) |

## 5. JOINT Classification Markings

### 5.1 Format

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S5.c** | All JOINT markings (banner and portion) begin with `//JOINT` | S5.c |
| **E4-S5.d** | Required banner format: `//JOINT [classification] [country codes]` | S5.d |
| **E4-S5.d.restr** | If US is NOT a co-owner, classification may be RESTRICTED. Where US IS a co-owner, RESTRICTED may NOT be used. | S5.d |
| **E4-S5.e** | Country codes (including USA) listed in alphabetical order, separated by spaces | S5.e |
| **E4-S5.e.note** | USA placement in JOINT is alphabetical (unique to JOINT; differs from REL TO where USA is first) | S5.e |

### 5.2 Portion Marking Rules

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S5.f** | Country codes are NOT included in portion markings when all portions match the banner country codes | S5.f |
| **E4-S5.f.extract** | If a JOINT portion is extracted into a non-JOINT U.S. document, country codes MUST be listed alphabetically in portion markings: `(//JOINT [classification] [country codes])` | S5.f |

### 5.3 Derivative Document Rules

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S5.g** | JOINT portions must be segregated from U.S. classified information in derivative documents | S5.g |
| **E4-S5.g.banner** | Banner of derivative U.S. document uses highest classification of all portions as a U.S. classification | S5.g |
| **E4-S5.g.nojoint** | JOINT marking is NOT carried to the banner line; used only in applicable portions | S5.g |
| **E4-S5.g.fgi** | FGI markings shall be added to the banner line with all non-U.S. country codes from JOINT portions | S5.g |

### 5.4 JOINT with REL TO

| ID | Requirement | Example Banner | Example Portion | Source |
|----|-------------|----------------|-----------------|--------|
| **E4-S5.fig31** | JOINT information may be combined with REL TO | `//JOINT SECRET GBR USA//REL TO USA, AUS, CAN, GBR, NZL` | `(//JOINT S//REL)` | Figure 31 |
| **E4-S5.fig31.rel** | `(REL)` may be used in portion if REL TO country list matches banner line | | `(//JOINT S//REL)` | Figure 31 |

### 5.5 Classification Authority

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S5.h** | Classification authority block is used ONLY when the United States is one of the co-owners | S5.h |

## 7. SAP Control Markings

### 7.1 Banner Format

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S7.c** | Banner: classification, caveat "SAR" or "SPECIAL ACCESS REQUIRED", and nickname/code word with dissemination control if assigned | S7.c |
| **E4-S7.c.hyphen** | Hyphen (`-`) without spaces separates "SAR" and the program nickname/codeword | S7.c |
| **E4-S7.c.slash** | Forward slash (`/`) separates multiple nicknames/codewords | S7.c |
| **E4-S7.c.noPID** | Assigned program identifiers (PIDs) shall NOT be used in the banner line | S7.c |

### 7.2 Portion Format

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S7.d** | Portion: classification, SAR, and the program's assigned PID (e.g., `TS//SAR-BP`) | S7.d |
| **E4-S7.d.hyphen** | Hyphen without spaces separates SAR and PID | S7.d |
| **E4-S7.d.multi** | Multiple PIDs listed alphabetically, separated by a slash | S7.d |

### 7.3 Multiple Programs

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S7.e** | When 3+ SAPs in a single document, use `SAR-MULTIPLE PROGRAMS` in banner (e.g., `SECRET//SAR-MULTIPLE PROGRAMS`) | S7.e |
| **E4-S7.e.portions** | When there are multiple programs, the PID for each SAP MUST be cited in the portion marking regardless of total number of PIDs | S7.e |
| **E4-S7.e.alpha** | Multiple PIDs in portion markings must be listed alphabetically, separated by `/` | S7.e |

### 7.4 WAIVED

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S7.f** | SAPs exempted from Congressional reporting: marked "WAIVED" in banner, portion marks, and on media (e.g., `TOP SECRET//SAR-BP//WAIVED`) | S7.f |
| **E4-S7.f.dissem** | "WAIVED" is used as a dissemination control marking | S7.f |

### 7.5 HVSACO

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S7.g** | HVSACO (Handle via Special Access Channels Only) is a handling instruction, NOT a classification level or dissemination control | S7.g |
| **E4-S7.g.apply** | Applied to non-SAP material (classified or unclassified) within a SAP environment (e.g., `SECRET//HVSACO`, `UNCLASSIFIED//HVSACO`) | S7.g |

| ID | Requirement | Source |
|----|-------------|--------|

| **E4-S9.d** | Use `FGI` with trigraphic country codes and international organization tetragraphs in the banner line | S9.d |

### 9.2 FGI with NOFORN and REL TO

| **E4-S9.l** | REL TO cannot be used in overall classification of a document containing FGI portions UNLESS the entire document is releasable to all countries listed | S9.l |

## 10. Dissemination Control Markings

### 10.1 FOUO (For Official Use Only)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.b.1** | FOUO is a control marking for unclassified information | S10.b.(1) |
| **E4-S10.b.3** | FOUO portions within a classified document shall be marked `(U//FOUO)` | S10.b.(3) |
| **E4-S10.b.3a** | FOUO shall NOT appear in the overall classification banner of a classified document (classification adequately protects the unclassified info) | S10.b.(3) |
| **E4-S10.b.3b** | Exception: When page markings reflect per-page classification, unclassified pages with FOUO use banner: `UNCLASSIFIED//FOR OFFICIAL USE ONLY` or `UNCLASSIFIED//FOUO` | S10.b.(3) |

### 10.2 ORCON (Originator Controlled)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.c.3** | ORCON may be used with TOP SECRET, SECRET, or CONFIDENTIAL | S10.c.(3) |
| **E4-S10.c.4** | Banner: `[classification]//ORCON`. Portion: `([classification]//OC)` | S10.c.(4) |
| **E4-S10.c.4a** | If any portion is ORCON, ORCON must appear in the banner line | S10.c.(4) |

### 10.3 REL TO (Authorized for Release To)

| ID | Requirement | Source |
|----|-------------|--------|
| **E4-S10.d.3** | REL TO may be used with TOP SECRET, SECRET, CONFIDENTIAL, or CUI | S10.d.(3) |
| **E4-S10.d.4** | Format: `[classification]//REL TO [country codes]` | S10.d.(4) |
| **E4-S10.d.4.order** | Trigraphic country codes listed: USA first, then other countries alphabetically, then coalition/organization tetragraphs alphabetically. Separated by comma and space. | S10.d.(4) |
| **E4-S10.d.5** | "REL TO USA" without any other countries is NOT an approved marking | S10.d.(5) |
| **E4-S10.d.6** | Portion marking `(REL)` may be used when portion's releasable countries are the same as banner line REL TO countries | S10.d.(6) |
| **E4-S10.d.6a** | If countries are different, portion marking must list all applicable countries | S10.d.(6) |
